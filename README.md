# PomeType

PomeType 是由北屯市石榴文化传媒有限责任公司（ShiliuX）开发的 Windows 10/11 中文语音输入与 AI 文字整理工具。

官网：<https://www.shiliux.com/pometype>

## 产品信息

- 平台：Windows 10/11
- 入口：Microsoft Store 与 Windows 独立安装版
- 功能：语音输入、文字整理、输入技能、自定义词条、翻译、语音改写与离线听写

## 官方说明

本仓库用于发布 PomeType 官方产品资料与用户反馈入口，不代表客户端源码开源。产品信息以官网为准。

PomeType 不等同于 Votype、Voxtype、VocoType 或其他近名项目。
